## 🚧 Khó khăn và giải pháp

### Vấn đề 1: CORS lỗi khi gọi API từ frontend
- **Mô tả**:  Lỗi CORS khiến frontend không fetch được dữ liệu
- **Impact**:  UI không nhận được kết quả
- **Root Cause**: Lambda function chưa cấu hình header Access-Control-Allow-Origin
- **Solution**: Bật CORS trong lambda function và chỉnh trong response của Lambda
- **Result**:  Giao tiếp frontend-backend hoạt động ổn
- **Lesson**: Khi làm web API, CORS là thứ cần kiểm tra ngay từ đầu
