## 💼 Công việc đã thực hiện

### 1.  Cấu hình logging từ Lambda tới CloudWatch ⏱️ 4 giờ
- **Mô tả**: Tích hợp CloudWatch Logs với Lambda function để ghi lại chi tiết truy vấn: query params, thời gian phản hồi, status code và message lỗi nếu có.
- **Kết quả**: Log đã được ghi đầy đủ theo format JSON giúp dễ dàng filter và phân tích sau này.
- **Tools/Tech**: WS Lambda, CloudWatch Logs

### 2. Tạo custom metrics và alarm ⏱️ 2 giờ
- **Mô tả**: Tạo metric filter cho các lỗi HTTP (4xx, 5xx) và timeout; sau đó thiết lập CloudWatch Alarm để gửi SNS notification khi vượt ngưỡng.
- **Kết quả**: Đã tạo 2 Alarm cho ErrorRate >= 5% và Timeout >= 2 trong vòng 5 phút.
- **Tools/Tech**: CloudWatch Metrics, CloudWatch Alarms, SNS, AWS CLI

### 3. Kiểm thử hệ thống logging và cảnh báo ⏱️ 2 giờ
- **Mô tả**:  Gửi các truy vấn lỗi/thời gian chờ để kiểm tra log và test alarm kích hoạt.
- **Kết quả**: Cảnh báo được gửi chính xác qua email, log ghi đúng thông tin.
- **Tools/Tech**: Postman, AWS SNS, CloudWatch Logs Insights
